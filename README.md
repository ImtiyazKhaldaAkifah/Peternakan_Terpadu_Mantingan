# Peternakan Terpadu Mantingan 🐄🌿

Website profil dan sistem informasi untuk **Peternakan Terpadu Mantingan**. Project ini menyediakan informasi seputar profil peternakan, koleksi produk/komoditas unggulan, serta formulir konsultasi interaktif yang terhubung langsung dengan database.

## ✨ Fitur Utama
- **Landing Page**: Informasi umum dan sambutan Peternakan Terpadu Mantingan.
- **Koleksi Ternak/Komoditas**: Menampilkan daftar produk unggulan secara dinamis dari database.
- **Form Konsultasi**: Pengunjung dapat mengirimkan pertanyaan atau permintaan konsultasi yang akan disimpan ke database.
- **Panel Admin**: (Opsional, sesuaikan dengan project Anda) Halaman untuk mengelola data produk dan pesan konsultasi.

## 🛠️ Teknologi yang Digunakan
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla), Bootstrap 5
- **Backend**: PHP 8.x
- **Database**: MySQL (MariaDB)
