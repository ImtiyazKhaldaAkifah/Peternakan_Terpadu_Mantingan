## 📖 Tentang Project
**Peternakan Terpadu Mantingan** adalah sebuah website profil dan sistem informasi yang dirancang untuk mendigitalisasi operasional peternakan. Project ini memungkinkan pengunjung untuk melihat informasi profil, mengeksplorasi koleksi produk/komoditas unggulan secara dinamis, dan mengirimkan form konsultasi yang terintegrasi langsung dengan database.

## ✨ Fitur Utama
- [x] **Landing Page Interaktif**: Menampilkan sambutan dan informasi umum peternakan dengan desain modern.
- [x] **Katalog Komoditas Dinamis**: Menampilkan daftar produk ternak yang datanya ditarik langsung dari database MySQL via API PHP.
- [x] **Formulir Konsultasi**: Pengunjung dapat mengirimkan pertanyaan yang akan tersimpan aman di database.
- [x] **Panel Admin**: Halaman khusus untuk mengelola data produk dan melihat pesan masuk dari pengunjung.
- [x] **Responsive Design**: Tampilan optimal baik diakses melalui PC, tablet, maupun smartphone.
